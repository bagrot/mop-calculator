# Актуальная версия приложения МОП

Дата фиксации: 12.08.2026

Эта папка является контрольной точкой проекта. Новые изменения нужно вносить с сохранением возможности вернуться к этой версии.

## Что работает

### Калькулятор МОП

- загрузка реестра голосов XLSX/XLSM;
- выбор строк и группировка по помещению и кадастровому номеру;
- поддержка нескольких кадастров для одного номера помещения;
- ручное добавление комнат;
- редактирование общей, жилой площади и площади МОП;
- автоматическое распределение МОП по комнатам;
- редактирование актуального номера помещения;
- удаление отдельных строк комнат;
- удаление помещения целиком;
- отметка карточки кнопкой «Обработано» с бледно-зелёным оформлением;
- экспорт итогового XLSX.

### Готовые МОПы

- отдельная вкладка под калькулятором;
- загрузка файла подсчитанных МОПов и реестра голосов;
- выбор листов;
- выбор кадастрового номера;
- выбор площади с МОП;
- выбор номера помещения из одного или двух столбцов;
- объединение файлов по кадастровому номеру;
- формирование номера вида «25 к.6»;
- формат дат `дд.мм.гггг`;
- площадь с МОП в формате `25.812`;
- предпросмотр и экспорт объединённого XLSX.

## Папки результатов

Результаты сохраняются в документах пользователя:

- `Обработка голосов/results/Калькулятор МОП`;
- `Обработка голосов/results/Готовые МОПы`.

Вкладка «Результаты» открывает основную папку результатов.

## Запуск и сборка

- `desktop/main.mjs` — окно Electron и встроенный обмен с приложением;
- `desktop/preload.cjs` — IPC-мост;
- `server.mjs` — обработка XLSX и экспорт;
- `public/` — интерфейс;
- `package.json` — настройки сборки;
- `MOP_Installer.exe` — актуальный установщик Windows.

Приложение не требует установленного Node.js и не использует внешний порт.

## Правило дальнейшей работы

Перед существенными изменениями создавать новую контрольную копию. Папку `АКТУАЛЬНАЯ_ВЕРСИЯ_МОП` считать базовой версией для возврата.
